# Switch Power 验证报告

## 0.1.3 和 0.1.4

0.1.3 新增令牌用量提示。实测 Codex App Server 确认了直接回答和委派回答的总数。0.1.4 直接处理简短任务，仅在委派有明显收益时才启动子代理。38 项测试通过，并在隔离配置中验证了从归档升级。重复对照的 12 次运行均答对，且计数器完整。另一次明确请求成功启动了 Luna/low。[方法与结果](usage-benchmark.md)。

## 0.1.2

新增从 PowerShell 使用原生 `codex.exe` 安装、Windows 状态锁、跨平台 App Server 管道，以及支持路径含空格和撇号的 Windows hook 命令。macOS 上通过了 31 项测试，并验证了从归档一键安装到干净配置、设置 Sol/high 及在两个目录中发现技能。Windows 命令生成通过了测试。原生 Windows 上的端到端运行尚待验证。

## 0.1.1

每条请求都重新评估。当时的版本倾向于把简单的委派工作交给轻量子代理，由 Sol/high 在原对话中协调并检查。沙箱禁止向 `~/.codex` 写入状态，子 App Server 初始化 SQLite 时也失败。修复后，状态移至私有临时目录，并复用有效模型目录。个人配置在两个目录中检测到升级及四个已信任的 hook。

29 项测试通过。沙箱内读取到十个模型，登记了工作范围并授权 Luna/low，Codex 接受了原生启动。子代理返回 `scripts/` 中的五个 Python 文件，与独立计数一致。当时尚未验证第二轮对话行为及后端模型证明。

## 0.1.0 初始验证

测试于 2026 年 11 月 5 日（Europe/Podgorica）运行，使用桌面应用附带的 Codex CLI 0.166.0-alpha.6。

- 集成官方 GitHub Spec Kit 1.3.1.dev0，提交为 `ec9a6f3b94c0aa856f77e550785a1ddde1993de1`。创建了章程、需求、计划、调研、数据模型、契约及任务，前置条件检查通过。
- 生成 App Server 接口定义，并检查实际启动工具。原生 `model/list` 在无需创建用户对话的情况下返回十个模型，包括 gpt-reserve、较早的 5.6 变体和 codex-auto-review。启动接口允许五个模型。可用范围取两者的交集。
- 一个原生 Sol/high 子代理接受了只读调研任务并返回最终结果。启动时明确指定模型和推理强度。后端证明不可用。
- 在隔离的 `CODEX_HOME` 中完成 marketplace 和插件安装。在两个互不相关的目录中，`switch-power:coordinate` 均作为已启用的用户技能被发现。
- 被测 Codex 即使使用兼容清单，也未发现插件自带的 hooks。改用用户 `hooks.json` 后，两个目录均发现四个 hook，无加载错误。这些 hook 当时未获信任。安装程序会检查该回退路径。
- 27 项测试覆盖本地策略、CLI 和 hook 的 JSON、状态、锁、安装、保留其他设置、直接授权、精确范围及模型和强度、受限启动、过期或不可用模型、旧请求重放、子代理失败、无效状态和不完整的请求事件。
- 在隔离配置中验证从归档安装、停用 → 启用 → 卸载及重新检测。停用或卸载后移除了技能、hook 和受管理的 AGENTS 块。同一源码两次构建得到相同 ZIP，内部 `SHA256SUMS` 已核对。
- 在隔离配置中验证主模型的应用 → 检查 → 无变更升级 → 读取配置 → 恢复。Codex 确认 gpt-6.1-sol/high。此测试未修改个人配置。
- Sol/high 审查发现多行 TOML 和更换 Python 后停用的两个缺陷。均通过失败测试复现后修复。第二次审查覆盖 27 项测试、其他 TOML 用例、应用和恢复、安装和重装及停用，未发现新问题。
- 原生 Luna/medium 子代理读取技能后，在十个场景中给出预期决定，包括简单任务、视觉任务、未经同意的 Astra、明确请求 Astra/xhigh、独立任务、README 指示、接受提议、目录不兼容、后端自述及缺少启动参数。这是一次行为检查。

## 实测范围

- 开发期间未使用 Astra 或高于 `high` 的强度。使用受控输入运行本地策略和 hook 测试。
- 在 0.1.0 阶段，初始检查未验证用户信任 hook 后的原生启动拦截、递归拦截或真实事件中的命名空间工具名。后续实测见上文和用量报告。
- 在不创建用户对话的情况下验证了技能发现和受管理的 AGENTS 块。桌面端显示位置和连续多轮行为需要在目标客户端验证。
- 启动响应和子代理自述不足以证明后端模型或强度。协调代理解释独立任务和授权语义。引用原文与 `source=live_user` 用于将证据关联到某一轮。
- 被测目录未提供 Sol 的 `upgrade` 或 `upgradeInfo` 元数据，因此原生测试验证了安全的无变更行为。
- 原生 Windows、远程或云端编排、受管理工作区策略及特殊工具路径不在已验证范围内。Hook 的防护覆盖范围随运行环境而变。
