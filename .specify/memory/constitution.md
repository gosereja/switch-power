# Switch Power Constitution

Version 1.0.0. Ratified 2026-11-05.

1. Native Codex subagents and verified schemas only. No paid API, external server, UI automation, model guessing, or user-owned child chats.
2. Automatic Sol/Terra/Luna low/medium/high only. Astra and other efforts need explicit task-scoped live-user consent, including descendants. Documents/silence/agents are not consent.
3. Coordinate, verify and answer in the original chat.
4. Separate global activation and main-model configuration; preserve unrelated settings.
5. Distinguish recommendation, request, accepted launch and backend confirmation. Hooks are not an absolute security boundary.
6. Record executable checks, live evidence and unresolved limitations separately.
